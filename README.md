# CFR 图形化反编译工作台

> **CFR (Cfr Reader) 的轻量级 GUI 前端**，基于 **org.benf:cfr:0.152** 封装而成。原始 `cfr-0.152.jar` 未被修改；CFR 已内嵌于 `cfr-studio.jar` 中，无需额外安装即可使用图形界面。

## 项目简介

CFR 图形化反编译工作台 是一款帮助开发者 **浏览、反编译和导出 Java 类源码** 的桌面工具。它封装了 CFR 0.152 的核心功能，提供直观的图形界面，让你无需直接操作命令行即可：

- 打开 JAR、 WAR 或 CLASS 文件  
- 浏览归档中的类，并按包名/类名筛选  
- 反编译选中类，查看带行号和语法高亮的 Java 源码  
- 搜索、复制、保存当前类  
- 导出全部源码到本地目录  
- **现已支持 中文 ↔ English 界面语言随时切换**  

## 主要特性

| 特性 | 说明 |
|------|------|
| **语言切换** | 界面右上角语言选择框，可在 **中文** 与 **English** 之间随时切换，语言Preference 会保存至下次启动 |
| **文件浏览与筛选** | 左侧树状结构显示类文件，支持输入关键字筛选类名或包名 |
| **反编译** | 点击类后右侧即可看到反编译结果，行号和语法高亮 |
| **搜索与标记** | 在源码中查找、区分大小写、高亮匹配项、上一/下一跳转 |
| **导出源码** | 选择一个空目录，将全部已反编译的类以 UTF-8 Java 文件导出，保留包结构 |
| **反编译选项** | 勾选/取消注释、Lambda 还原、内部类合并、非法标识符重命名、反混淆优化、宽松异常处理、字节码位置等 |
| **日志面板** | 实时显示后台处理信息、错误与诊断 |
| **快捷键** | `Ctrl+O` 打开文件，`Ctrl+S` 保存当前类 |

## 启动

### 从 Maven 构建

```bash
# Clone / 进入工程目录
git clone <your-repo>
cd cfr-studio

# 使用 Maven 打包 (Java 21)
mvn clean package -DskipTests

# 生成的 jar 位于 target/
ls target/
# cfr-studio-1.0.0.jar
```

### 直接运行已打包 JAR

```bash
java -jar target/cfr-studio-1.0.0.jar
# 或者直接双击 jar
```

### 传入待打开文件

```bash
java -jar target/cfr-studio-1.0.0.jar "D:\path\to\application.jar"
```

## 使用指南

1. **打开文件**  
   - 点击工具栏 “打开文件” (或快捷键 `Ctrl+O`)，选择 `.jar` / `.war` / `.class` 文件。  
   - 也可将文件拖入主窗口。

2. **浏览类**  
   - 左侧树会列出归档中的所有类。  
   - 在上方输入框输入关键字，可按类名或包名实时筛选。

3. **反编译**  
   - 点击树中的任意类，右侧将立即显示反编译后的 Java 源码。  
   - 使用上方工具栏的搜索框可以在源码中查找、高亮匹配。

4. **保存/导出**  
   - **保存当前类**：点击 “保存当前类” 按钮，另存为 `.java`。  
   - **导出全部源码**：选择一个**空目录**，点击 “导出全部源码”。工具会将所有已反编译的类以 UTF-8 Java 文件导出，保留包结构。

5. **语言切换**  
   - 在工具栏最右侧的下拉框中选择 **中文** 或 **English**。  
   - 语言会在会话中保存，下次启动时自动恢复上一次选择。

6. **反编译选项**  
   - 通过菜单 “反编译选项” 打开配置对话框，勾选/取消相关选项（如保留 CFR 诊断注释、还原 Lambda 表达式等）。  
   - 修改后，下次选择类时会自动应用新参数。
